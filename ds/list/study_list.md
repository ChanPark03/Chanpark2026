# 연결 리스트 (Linked List) 스터디 가이드 - list1.c 완전 쉽게 설명!

## 1. 연결 리스트가 뭘까? (초보자용 비유)

연결 리스트는 **기차**와 같아요! 
- 각 기차 객차(Node)가 데이터(숫자 등)를 가지고 있고
- 객차마다 다음 객차를 가리키는 **손잡이(next)**가 있어요
- 기차 머리(첫 번째 객차)를 잡고 있으면(p 포인터) 전체 기차를 따라갈 수 있어요!

```
머리(p) → [100 | next] → [200 | next] → [300 | next] → [400 | next] → NULL
          ↑ 객차(Node): data + next 포인터
```

## 2. list1.c 코드가 뭘 하는지? (단계별로!)

### (1) 기차 만들기 (main 함수 시작)
```c
Node *p = malloc(sizeof(Node));  // 첫 번째 객차 생성
p->data = 100;                   // 데이터 넣기
p->next = malloc(sizeof(Node));  // 다음 객차 연결
p->next->data = 200;
// ... 계속 300, 400 객차 추가
```
**결과**: 100 → 200 → 300 → 400 기차 완성!

### (2) 삽입하기 insertNode() - 새 객차 끼워넣기
```c
insertNode(30, p);     // p 다음에 30 끼우기
insertNode(40, p->next); // 200 다음에 40 끼우기
```
**어떻게?**
```
원래: 100 → 200 → 300
끼우기: 새 객차(30) 만들고, 100의 next를 새 객차로 바꾸고, 새 객차의 next를 기존 200으로!
결과: 100 → 30 → 200 → 300
```

### (3) 삭제하기 deleteNode() - 객차 떼어내기
```c
deleteNode(p, 300);  // 300 객차 찾아서 제거
```
**어떻게?**
- 앞 뒤 객차(prev, curr) 찾아서 연결 바꾸기
- 300 객차 free()로 메모리 해제
**결과**: 100 → 30 → 200 → 400 (300 사라짐!)

### (4) 출력하기 - 기차 전체 출력
```c
Node *tmp = p;
while(tmp) {  // tmp가 NULL까지
    printf("%d\n", tmp->data);  // 데이터 출력
    tmp = tmp->next;            // 다음 객차로!
}
```
**출력**:
```
100
30
200
40
400
```

### (5) 문제점들 (버그 발견!)
⚠️ **deleteList() 함수는 잘못됐어요!**
- 하드코딩(1,2 같은 숫자)으로 되어 있어서 4개 이상 객차면 망함
- 모든 객차를 순서대로 제거해야 하는데 안됨

**올바른 deleteList()는 이렇게:**
```c
void deleteList(Node *p) {
    Node *tmp;
    while (p->next != NULL) {  // 다음 객차가 있을 때까지
        tmp = p->next;         // 다음 객차 임시 저장
        p->next = tmp->next;   // 건너뛰기
        free(tmp);             // 임시 객차 버리기
    }
}
```

## 3. 핵심 구조체 Node 이해하기
```c
typedef struct node {
    int data;          // 객차 짐 (데이터)
    struct node *next; // 다음 객차 손잡이 (포인터)
} Node;
```
- `->` : 포인터로 구조체 멤버 접근 (p->data = (*p).data와 같음)

## 4. 메모리 관리 꼭 기억!
- `malloc()`: 새 객차 만들기 (메모리 할당)
- `free()`: 객차 버리기 (메모리 해제)
- 안 하면 **메모리 누수** (기차가 도로에 쌓임!)
